# stroke_project
2025년 1학기 프로젝트 최종고서

주제 : Python을 이용한 뇌졸중 탐색적 데이터 분석

1.1. 해결하고자 하는 문제

뇌졸중은 세계 2위 사망 원인으로, 사망률이 높고, 치료 골든타임을 놓치면 뇌세포가 빠르게 죽어가 반신마비, 언어장애, 시각장애, 인지저하등 후유증이 발생할 수도있고 심할 경우 사망에 이르기도 하는 위험한 질환입니다.

따라서 뇌졸중은 예방이 중요한데 고혈압, 심장질환, 당뇨, 흡연, 비만 등 위험 요인이 명확한 편이라 미국의 심장·뇌졸중학회(AHA,ASA)는 “뇌졸중의 약 80%는 예방 가능하다.”라고 직접 언급하였고, 조기 검진과 생활습관 개선을 통해 예방 가능하다고 말하고 있습니다. 이를 보아 뇌졸중은 충분히 예방 가능한 질환임을 알 수 있습니다.

1.2. 문제 해결 방법의 필요성 (혹은 연구 배경)

나이, 고혈압, 심장병, 흡연 여부, BMI 등은 뇌졸중 발생과 연관이 있습니다. 하지만 이 요인들이 실제로 어떻게 뇌졸중과 연관이 있는지에 대한 객관적인 지표가 필요합니다. 또한 상대적으로 의미 없는 요인은 무엇인지를 확인하려면 데이터 시각화를 통한 인사이트가 필요합니다.

따라서 본 프로젝트는 캐글 뇌졸중 데이터 셋을 바탕으로, 다양한 변수 간의 관계를 시각화하여 뇌졸중을 예방할 수 있는 인사이트를 알아가는 것 을 목표로 설정했습니다.

3. 결과

3.1. 문제 해결 결과 분석

데이터 분석 결과 나이, 고혈압, 심장병, 평군 포도당(혈당) 수치, BMI지수는 뇌졸중의 주요 발생 요인이라는 것을 알 수 있습니다.

평균적 60대이상 남자가 상대적으로 여성보다 조금 더 쉽게 뇌졸중에 걸리는것으로 나타났습니다.
이전에 흡연을 했었거나 흡연자 일경우, 뇌졸중의 가능성이 높았습니다.
WHO 세계 보건기구 기준 BMI 지수는 30 이상일 경우 비만으로 보는데, BMI지수가 30이상이고 평균 포도당(혈당) 수치가 150이상일 경우 뇌졸중에 쉽게 걸리는것으로 나타났습니다.
고혈압과 심장병은 원래 뇌졸중의 높은 원인으로 알려져있는데 두개 다 해당된 경우 뇌졸중 발생률이 굉장히 높아진다는 것을 알 수 있습니다.
실제 의료 분야에서도 이 조건들은 전형적인 뇌졸중 고위험군에 해당하며, 예방적 개입이 필요한 신호로 간주됩니다. 따라서 이 조합들은 뇌졸중 발생을 설명할 수있는 중요한 인사이트라고 생각합니다.
3.2. 향후 과제 (미진한 내용 혹은 향후 더 연구가 필요한 내용 등)

EDA를 만든것으로 끝나는 게 아닌 로지스틱 회귀나 결정트리 기반 알고리즘등을 이용해 머신러닝 모델을 만들어볼 계획입니다.
남녀 성별 별로 분리된 분석이 필요하다. 여성은 폐경 전후, 연령대에 따라 뇌졸중 위험요인의 양상과 민감도가 남성과 다르게 나타나며, 이 때문에 성별별로 분리된 분석이 반드시 필요하다는 의견입니다. 또한 AHA/ASA 뇌졸중 예방에서 여성은 별도 지침이 필요하다고 명시했습니다.
